# Red de Vida

Sitio estático para acompañar el bienestar emocional. Abre `index.html` para empezar; la navegación conecta estas secciones:

- `checkin.html`: registra el estado de ánimo del día.
- `perfil-usuario.html`: edita el perfil y consulta el historial semanal guardado en el navegador.
- `musica.html`, `arte.html`, `meditacion.html` y `match.html`: explora las demás secciones.

El check-in y el perfil comparten los registros mediante `localStorage` del mismo navegador. Las páginas principales usan `estilos.css`; el perfil mantiene `styles.css` y el check-in agrega `checkin.css`.
